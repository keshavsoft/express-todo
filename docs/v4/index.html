express-todo

Simple Express boilerplate generator for quickly starting backend projects.

Installation 

npx express-todo simple

What It Generates

Express Setup

Ready-to-use server structure.

Config Files

Starter configuration included.

Environment Files

Includes .env and .env.local.

VS Code Support

Includes .vscode setup.

Generated Structure 

project-name/

├── .vscode/
├── Config/
├── Public/
├── .env
├── .env.local
├── app.js
├── config.json
├── configLoader.js
├── package.json
├── package-lock.json
├── port.js
├── routes.js
└── server.js

Example 

npx express-todo simple

cd your-project-name
