# express-todo

Simple Express boilerplate generator for quickly starting Express applications.

---

# Installation

## Using NPX (Recommended)

```bash
npx express-todo simple
```

---

# What It Does

The command:

```bash
npx express-todo simple
```

automatically creates a ready-to-use Express project with basic structure and starter configuration.

---

# Generated Structure

```txt
project-name/
│
├── .vscode/
├── Config/
├── Public/
├── .env
├── .env.local
├── app.js
├── config.json
├── configLoader.js
├── package.json
├── package-lock.json
├── port.js
├── routes.js
└── server.js
```

## Command

# Quick Start

## Step 1

Create project:

```bash
npx express-todo simple
```

## Step 2

Move into project folder:

```bash
cd your-project-name
```

## Step 3

Install dependencies:

```bash
npm install
```

## Step 4

Start server:

```bash
npm start
```
